# connected_cockles

Integrating larval connectivity from a biophysical dispersal model into species
distribution models for cockles (*Cerastoderma edule*) in the Limfjord, Denmark.

Data are kept local (see `.gitignore`); this repository tracks the analysis
scripts, figures, tables, and the manuscript only.

## Layout

```
R/            analysis scripts (numbered = pipeline order)
data/         local only, never tracked
  raw/        read-only inputs; nothing in here is written by code
  derived/    everything the pipeline writes; safe to delete and rebuild
output/
  figs/       fig1..fig3 (main text), figS1..figS6 (supplementary)
  tables/     tab1, tab2 (LaTeX, \input directly by the manuscript)
manuscript/   main.tex, bibliography, and style files
```

Figure and table files are numbered in the order they appear in the manuscript,
so `fig2_coeff.png` is Figure 2 and `figS3_coeff_presence.png` is Supplementary
Figure S3. Renumbering means renaming in the producing script and in `main.tex`.

The `raw` / `derived` split is the load-bearing one: if a file is in `derived/`
it can always be regenerated by re-running the pipeline, so only `raw/` needs
backing up.

### `data/raw/`

| Folder | Contents |
|--------|----------|
| `cockles/` | Cockle survey shapefile (biomass, presence, environment per station) |
| `connectivity/matrices/` | ABM connectivity matrices, `ABM_cmn_<year>.csv` and `_all` |
| `connectivity/release/` | Release vectors per source cell, `ABM_rel_<year>.csv` |
| `connectivity/matrices_pld/` | Alternative pelagic-larval-duration matrices (not currently used) |
| `environment/` | Bathymetry raster; EUSeaMap habitat layers |
| `boundaries/` | Coastline (`land_small_utm`) and Limfjord water outline |

### `data/derived/`

Written by the pipeline, in this order: `cockles_clean.rds`, `spatial_grid.rds`,
`flow_matrix_{2010..2016,all}.rds`, `avg_biomass_grid.rds`,
`weighted_flow_matrix_*.rds`, `connectivity_weighted_*.rds`,
`connectivity_by_year.rds`, `cockles_connectivity.rds`,
`cockles_connectivity_sensitivity.rds`, `sdm_fits.rds`,
`sdm_model_comparison.rds`.

## Pipeline (`R/`)

Run in numerical order; the figure and table scripts can be run once `06` has
produced the fits.

| Script | Purpose |
|--------|---------|
| `00_clean_cockles.R` | Clean the cockle survey data, attach depth |
| `01_compute_flow_matrix.R` | Flow (settlement-probability) matrices, per year and pooled |
| `02_make_grid.R` | Build the 2 km spatial grid |
| `03_predict_avg_biomass.R` | Predict mean biomass / presence onto the grid |
| `04_weight_flow_matrix.R` | Weighted supply and structural graph metrics, per flow matrix |
| `05_extract_connectivity.R` | Attach metrics to survey observations (+ per-year sensitivity set) |
| `05b_plot_connectivity.R` | Supplementary map of the connectivity metrics |
| `06_fit_sdm.R` | Fit and compare the spatial SDMs (presence, biomass) |
| `07_variance_partitioning.R` | Variance partition, with and without the spatial field |
| `fig1_study_area.R` | `fig1_map` — study area and connectivity clusters |
| `fig2_coefficients.R` | `fig2_coeff` (biomass) and `figS3_coeff_presence` |
| `fig_covariates.R` | `figS1_covariates` — covariate maps |
| `figS_space_confounding.R` | `figS5_space_confounding` — connectivity with vs without the spatial field |
| `figS_connectivity_biomass_correlation.R` | `figS4_year_sensitivity` — sensitivity to the dispersal year |
| `tab_model_selection.R` | `tab1_model_selection` (LaTeX) |

`07_variance_partitioning.R` also writes `fig3_variance`,
`figS6_variance_nospace` and `tab2_variance_partitioning`;
`05b_plot_connectivity.R` writes `figS2_connectivity_metrics`.

## Connectivity metrics

Computed per grid cell in `04` from the flow matrix `F` (rows = source,
columns = sink): `biomass_in_strength`, `log_biomass_in_strength` and
`presence_in_strength` (incoming flow weighted by predicted source biomass or
occurrence), and the purely structural `deg_in`, `in_strength`,
`local_retention`, `eigen_centrality`, and `closeness_centrality` (the last on a
`log(1/p)` cost-transformed graph, after Costa et al. 2017).

## Models

Spatial GLMMs (`sdmTMB`) on an `fmesher` mesh with a land barrier: biomass
(Tweedie, log link) and presence (Bernoulli, logit link), with environmental,
gear, and connectivity covariates and a spatial random field. `06` rotates the
connectivity slot over five metrics across six model structures.

## Manuscript

`manuscript/main.tex` pulls figures and tables directly from `output/` via
`\graphicspath` and `\input`, so they cannot drift from the fitted models. It
requires XeLaTeX (fontspec / Libertinus Serif).

## Note on package versions

`sdmTMBextra` 0.0.5 calls `fmesher::fm_identical_CRS`, renamed in fmesher >= 0.7.
`03` and `06` register the old name as an alias at the top of the script; remove
those shims once `sdmTMBextra` is updated.
